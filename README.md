# Tapriwala – The Contemporary Tea Cafe (Coimbatore)

> **“The soul of a tapri. The warmth of your favourite cafe.”**

An exceptionally polished, interactive website prototype built for **Tapriwala – The Contemporary Tea Cafe**, Coimbatore. Designed to translate traditional Indian roadside chai culture into a warm, contemporary, and memorable digital dining experience.

---

## ☕ Key Highlights & Features

- **Art-Directed Editorial Aesthetics**:
  - Warm ivory and parchment backgrounds (`#F7F1E7`, `#FAF6EF`)
  - Deep chai brown typography (`#302019`)
  - Terracotta accents (`#B95032`), pistachio green badges (`#728064`), and sand dividers (`#E4D6C2`)
  - Editorial serif headlines paired with clean modern sans-serif UI typography and handwritten annotations
- **Opening Experience**:
  - Asymmetric hero with oversized clay kulhad chai composition
  - Realistic rising steam animation & rotating circular seal badge
  - Direct actions to explore menu or locate outlets
- **Our Story & Kitchen Standards**:
  - Split editorial layout highlighting 4 core culinary promises:
    1. 100% Pure Vegetarian
    2. Jain Options on Request
    3. No Artificial Colours or Packet Preservatives
    4. Pocket-Friendly Desi Snacks (Chai break for two: ~₹200–₹400)
- **Signature Introductions ("First visit? Start here.")**:
  - Tapriwala Special Chai (₹40) in clay kulhad
  - Surat Special Cold Cocoa (₹108) with dark chocolate curls
  - Mumbai Vada Pav (range ₹50–₹75) with dry garlic thecha
  - Paneer Cheese Burst Sandwich (₹140) with marinated paneer & cheese
  - Interactive dish modals with details, pricing, and ingredients
- **Interactive Cafe Menu ("What are you craving?")**:
  - Real-time search by dish name, ingredient, or tag
  - Category filters: Chai & Hot Brews, Cold Sips, Street Food & Chaat, Sandwiches & Wraps, Maggi
  - 1-click **Jain Friendly Only** filter toggle
  - Genuine Swiggy catalogue food photography
  - Accurate pricing with supplied ranges (₹50–₹75, ₹30–₹35) and "Ask in store" labels
- **Chai Companion Interaction ("Find your chai-time pairing")**:
  - Interactive pairing selector based on 4 moods (Quick Chai Break, Something Chocolatey, Desi Comfort, Cheesy Craving)
  - Celebratory confetti feedback with direct button to highlight the pair in the menu
- **The Tapri Experience**:
  - Deep espresso contrast section showcasing flagship cafe culture
  - Scrapbook layout highlighting indoor seating, board games on tables (Jenga, Scrabble, Uno), and warm ambient lighting
- **Coimbatore Outlets Selector**:
  - Interactive switcher between 3 locations:
    1. **R.S. Puram — Flagship Cafe**: 551-B Lokamanya Street (West), DB Road Corner
    2. **Saibaba Colony**: 32, Alagesan Road
    3. **Tapriwala Express**: 130, Venkatasamy Road West (Grab-and-Go Kiosk)
  - Real outlet storefront photos from Swiggy
  - Working **Get Directions** links to Google Maps with exact addresses
  - Clickable **Call this outlet** telephone links
- **Mobile First**:
  - Responsive layouts tested across mobile, tablet, and desktop
  - Sticky mobile action bar with >44px touch targets
  - Full keyboard accessibility (Escape key dialog dismissal, focus styles)

## 🚀 Running Locally

### Option 1: Quick Start (Windows)
Double-click `START_DEV.bat` in the root folder.

### Option 2: Terminal
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS keyframe steam physics
- **Hosting Ready**: Zero-config deployment configurations included for **Netlify** (`netlify.toml`, `_redirects`) and **Vercel** (`vercel.json`)
